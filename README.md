HCI HTML/CSS Website Activity
Task
Create a simple and user-friendly website using HTML and CSS.

Your website should demonstrate the HCI principles discussed in class.

Instructions
Create a website about a school, college, campus, or student services.
Your website must have a navigation bar with at least:
Home
About
Services
Announcements
Contact
Your Home page should include:
Website title/logo
Welcome message
Short description
At least one button
Navigation bar
Add at least 3 service cards, such as:
Library
Registrar
IT Support
Add an Announcements section with at least 2 announcements.
Add a Contact section with basic contact information.
Use CSS to design your website. Include:
Colors
Fonts
Spacing
Buttons
Hover effects
Cards
Make your website responsive so it can be viewed on desktop. 
Apply HCI principles:
Consistency
Visibility
Feedback
Accessibility
Easy Navigation
Visual Hierarchy
Submission Instructions
After completing your website, organize all your files in one folder.

Your folder should contain:

YourName_HCI_Website
│
├── index.html
├── style.css
└── images/
    ├── image1.jpg
    ├── image2.jpg
    └── image3.png
Before submitting:
Make sure your HTML file works properly.
Make sure your CSS file is connected to your HTML.
Make sure all images are included in the images folder.
Open your index.html and check that everything is displayed correctly.
ZIP the entire folder.
Rename the ZIP file using this format:
GROUP#_HCI_Website.zip

Important
Do not copy the sample website exactly.

You may change the:

Website name
Colors
Images
Content
Layout
Services
Be creative, but make sure your website is easy to understand and easy to use.
